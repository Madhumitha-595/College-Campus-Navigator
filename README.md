# College-Campus-Navigator
A smart campus navigation system that helps students and visitors find buildings, departments, classrooms, and important locations within a college campus using graph algorithms and shortest-path navigation.

## 📌 Project Overview

College Campus Navigator is a navigation system designed to help students, staff, and visitors find locations within a college campus easily.

The system represents the campus as a graph, where locations are vertices and the paths connecting them are edges. It uses graph algorithms to calculate the shortest route between two campus locations.

## 🎯 Objectives

- Help users navigate the college campus.
- Find the shortest path between two locations.
- Represent campus locations using graph data structures.
- Apply Data Structures and Algorithms to a real-world problem.
- Improve campus accessibility and save time.

## ✨ Features

- Display available campus locations.
- Select a starting point and destination.
- Calculate the shortest route.
- Display the route distance.
- Represent campus pathways using a graph.
- Provide a menu-driven navigation interface.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Data Structure:** Graph, Vector, Priority Queue
- **Algorithm:** Dijkstra's Shortest Path Algorithm
- **IDE:** Visual Studio Code
- **Compiler:** GCC (g++)

## ⚙️ How It Works

1. Campus locations are represented as graph vertices.
2. Connections between locations are represented as weighted edges.
3. The user selects a starting location and destination.
4. Dijkstra's algorithm calculates the shortest path.
5. The system displays the route and total distance.

## ▶️ How to Run

1. Install a C++ compiler such as GCC.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Compile the source file:

   ```bash
   g++ main.cpp -o campus.exe
   ```

5. Run the program in PowerShell:

   ```powershell
   .\campus.exe
   ```
